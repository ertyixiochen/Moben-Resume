# 墨本简历

一个纯前端、本地优先的简历制作工具 MVP。

## 运行方式

- 直接双击 `index.html` 打开。
- 或在本目录启动任意本地静态服务器后访问 `index.html`。
- 在本目录运行 `node tests/pdf-io.test.js` 可检查 PDF 文字提取、栏目识别和 Markdown 导出。

## 功能

- 首次打开显示虚构样例；线上更新时仅替换完全未改动的旧样例，保留已编辑简历。
- 若浏览器仍保留旧示例，可在“内容”面板点击“载入虚构示例”，确认后替换当前简历。
- 直接在 A4 简历纸张上修改个人信息、教育经历、工作经历、项目经历、技能清单和自定义模块。
- 个人信息支持本地照片，添加照片后简历自动切换为左文右图排版。
- 顶部“内容”面板可添加模块、补充未显示的字段、调整模块顺序和管理照片；纸张上可增删要点与条目、调整条目顺序。
- 选中纸张上的文字后，可通过浮动工具条加粗、设为斜体、加下划线、调整文字颜色或添加超链接。
- 教育经历的专业/学位、工作经历的岗位会和学校/公司保持同一行。
- 顶部提供字号、行距、栏目标题色调与智能一页；“内容”面板提供密度和分点符。
- “智能一页”会自动收紧行距、段距和页边距，尽量把内容放进一页 A4。
- A4 纸张即编辑区，按条目分页；模板切换入口已暂时注释，当前固定使用经典专业排版。
- “导出”菜单提供 PDF、JSON 和 Markdown。PDF 使用浏览器打印，可在打印窗口选择“另存为 PDF”；默认文件名为简历姓名。
- 栏目标题右侧分隔线使用打印稳定的边框线，导出 PDF 时更不容易丢失。
- “导入”仅接受 PDF。本地提取文字后先显示检查窗口，确认后替换当前简历；扫描图片 PDF 需先用其他工具完成 OCR。

## 隐私与存储

- 简历正文保存在当前浏览器的 IndexedDB。
- 字号、行距、密度、分点符和色调等偏好保存在 localStorage。
- 没有后端服务、账号登录、第三方统计、外部字体或 CDN。
- PDF 导入及 PDF/JSON/Markdown 导出只在本机浏览器中完成，不会上传文件。
- PDF 文字提取使用随项目打包的 Mozilla PDF.js 3.11.174（Apache-2.0），不依赖 CDN。

## 文件结构

- `index.html`：页面结构和入口。
- `styles.css`：编辑器、预览、A4 打印样式。
- `app.js`：IndexedDB、编辑、排序、导入导出、实时预览和分页逻辑。
- `pdf-io.js`：PDF 文字提取、栏目识别和 Markdown 导出。
- `vendor/`：本地 PDF.js 脚本及许可证。
- `tests/pdf-io.test.js`：PDF 提取、栏目识别和 Markdown 导出测试。
