# 墨本简历

一个纯前端、本地优先的简历制作工具 MVP。

## 运行方式

- 直接双击 `index.html` 打开。
- 或在本目录启动任意本地静态服务器后访问 `index.html`。

## 功能

- 个人信息、教育经历、工作经历、项目经历、技能清单、自定义模块的结构化编辑。
- 个人信息支持本地照片，添加照片后预览自动切换为左文右图排版。
- 模块增删、拖拽排序、上移、下移；模块内条目增删、上移、下移。
- 点击右侧简历预览中的姓名、联系方式、模块标题、经历条目或要点，可定位到左侧对应输入框继续修改。
- 编辑区选中文本后可通过浮动工具条设置加粗、斜体、下划线、蓝色或黑色。
- 教育经历的专业/学位、工作经历的岗位会和学校/公司保持同一行。
- “美化”浮窗集中提供字号、密度、分点符和栏目名称色调。
- “智能一页”会自动收紧行距、段距和页边距，尽量把内容放进一页 A4。
- 右侧实时 A4 预览，模板切换入口已暂时注释，当前固定使用经典专业排版。
- 浏览器打印，可在打印窗口选择“另存为 PDF”。
- 栏目标题右侧分隔线使用打印稳定的边框线，导出 PDF 时更不容易丢失。
- JSON 导入、导出，用于本地备份和迁移。

## 隐私与存储

- 简历正文保存在当前浏览器的 IndexedDB。
- 字号、密度、分点符和色调等偏好保存在 localStorage。
- 没有后端服务、账号登录、第三方统计、外部字体或 CDN。
- JSON 导入导出只在本机浏览器中完成，不会上传文件。

## 文件结构

- `index.html`：页面结构和入口。
- `styles.css`：编辑器、预览、A4 打印样式。
- `app.js`：IndexedDB、编辑、排序、导入导出、实时预览和分页逻辑。
